# 57 张图寻成品

三个区域各 19 张，分别从 #1 编到 #19。对应关系沿用共享格位 P01–P19，同一编号可在五个 Bingo 中共用。编号不是原表图片序号，映射见“区域编号对应表.csv”。

右下角统一使用奶白正面、橙金厚侧边、深蓝描边的圆胖 3D 编号。照片分别采用漫画、网点、线稿、建筑蓝图、局部遮挡、像素化、故障、选择性保色及不同调色方案。

成品位于“区域1”“区域2”“区域3”文件夹。57 张 PNG 合计约 120.4 MiB；“预览缩略图”仅供工作人员审阅页快速加载，不是比赛原尺寸素材。

使用内置 image_gen 逐张编辑，并在同一张成品中完成处理和编号。实际完整提示词见“实际处理提示词.json”；原表 63、57 的最终修正提示词见“修正处理提示词.json”。编号和主要定位线索已逐张目视核对；生成式处理仍可能改变细小纹理或次要文字，不宜将这些细节作为唯一审核条件。

两处特殊构图：区域3 #6（原表63）裁取原照片上方可见门头与天花并整块水平翻转，不补画人物挡住的背景；区域3 #16（原表57）保留完整全景，在上下加深蓝留边，避免拉伸或切掉左右定位线索。完整性校验中的两条比例变化是这两项有意处理。

原表序号 2、6、8、17、20、25、33、46、66 不纳入本次成品，其中 2 是此前单独指定的区域开场图，其余为备用照片。本次没有删除任何原图，也没有覆盖之前的五张样稿。66 张原始图片的 SHA-256 校验均与处理前一致。

“57张图寻成品预览.html”用于工作人员审阅，包含处理说明、原表编号和原图链接，不应直接发给选手。给选手或 Web App 使用时，只取三个区域文件夹中的 PNG；本次没有修改 Web App 或将图片直接接入游戏。
